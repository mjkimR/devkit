# Product clarification

1. Identify what the next useful action lacks: intended users, problem, constraints, representative usage or signs that the first version helps.
2. Reuse known answers; ask only the missing decision in plain language, with a recommended option when evidence supports one.
3. If the direction is open, compare a few candidates by the user's goal, trade-offs and assumptions worth testing.
4. Label user decisions, agent recommendations and unverified assumptions separately; a missing reply is no approval.
5. Choose the narrowest first version that exercises a representative flow; no complete backlog or architecture comes first.
6. If a concrete uncertainty blocks that version, start bounded research or implementation evidence instead of extending a fixed questionnaire.
7. Reopen only the question a working result invalidates, without restarting a formal planning lifecycle.

Example: for a shared household list, reuse the stated mobile-web constraint and ask whether two people edit at once before choosing storage; ask neither for the platform again nor for a feature backlog.
