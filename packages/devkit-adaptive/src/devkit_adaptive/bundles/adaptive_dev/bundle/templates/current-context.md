# Adaptive-dev current context

Keep current facts; remove template prompts that do not apply. This file is project-owned `.devkit/adaptive-dev.md`, not a Unit or immutable history.

## Goal and intended usage

Product goal, intended users, constraints, representative flow and signs of usefulness.

## Retained decisions and current choices

Separate user decisions, implementation choices and assumptions needing evidence. Record the reason that still matters.

## Documents

Map each retained behavior, structure or choice to its document ID, or to its path where the document has no ID; mark one without a document `undocumented`. Link, never copy document content. When the project has no document yet, say so here.

## Run and verify

Setup/run/check commands and required environment. For each observed result, name the source/artifact identity, actual command or interaction, outcome and limitation. Mark unexecuted or skipped checks as unverified.

## Open questions and limitations

Unresolved product or technical decisions and missing evidence that still affect work. When research notes exist, link their current evidence, surviving alternatives and conditions that would reopen a choice; link a retained research material by its `MAT-<slug>` ID.

When a failed approach still affects work, record its reason, source identity, owner, surviving hypothesis, retry condition and recovery action. Recheck applicability on resume.

## Next useful action

One next executable action and what its result will decide. Link current product documents or retained evidence when present.

Name outstanding assignments by ledger ID and their next recovery action; keep scope, base and checks in the ledger.
