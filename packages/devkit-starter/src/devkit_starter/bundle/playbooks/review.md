# Review procedure

## Prerequisites

A code change and its intended behavior are available for inspection.

## Procedure

1. Identify the intended behavior and inspect the change.
2. Check correctness, ownership boundaries and compatibility.
3. Run the relevant verification.

## Completion conditions

The report lists each concrete finding with its file reference, or states that there is none, and each
verification performed with its result.
