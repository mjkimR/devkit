# Review procedure

## Prerequisites

A code change and its intended behavior are available for inspection.

## Procedure

1. Identify the intended behavior and inspect the change.
2. Check correctness, ownership boundaries, and compatibility.
3. Run relevant verification and report findings with file references.

## Completion conditions

Report concrete findings with file references and the verification performed.
