# Documentation Guide

Use the document formats to describe the implementation and choices the project retains.

| Directory | Focus Area |
| --- | --- |
| **`architecture/`** | System structure with arc42 and C4 |
| **`decisions/`** | Current choices, context and reasons |
| **`capabilities/`** | Behavior and business rules |
| **`usecases/`** | Actor goals, steps and acceptance scenarios |
| **`ux/`** | UX Documents |
| **`materials/`** | Research evidence and experiments |
| **`development/`** | Setup, verification and collaboration |
| **`steering/`** | Background: `glossary.md`, `glossary.yaml` and project topics |

Run `uv run devkit get-context docs` before document work. Read the applicable writing instructions and steering bodies.
Capabilities and use cases link both ways. Describe retained behavior in current documents.
The project's selected development approach defines approvals, change tracking and decision retention.
