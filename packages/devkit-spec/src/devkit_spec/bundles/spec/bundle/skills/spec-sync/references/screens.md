# spec-sync reference: screens

Read from Step 1 when `spec.md` has a `Screens` section.

Write each draft of the spec's `Screens` section to `docs/ux/<area>/UX-<slug>.md` (template `ux`) with its step
citations to the use cases, and the `Screens` section's register rows to `docs/steering/ux-objects.md` for shared
objects or `docs/packages/<name>/steering/ux-objects.md` for namespace-specific objects; read both and create only a
register whose rows are needed. Make plain-text new IDs code spans. `RULE-ux-links` and `RULE-ux-coverage` check
screen links and step coverage; register semantics remain a review concern.
