# Host documentation extraction for adaptive lifecycle hooks

Scope: what the `scout` of this Planning run extracted from the vendors' documentation on 2026-11-10, item by item.
`host-capability-matrix.md` classes a cell `documented` only when this file holds the extraction.
The scout-01 envelope of the rejected proposal (commit `ad3d2ba3`) records the scout's findings; this file records its per-host table.

## 1. Limits of the extraction

- The fetch tool returns a model-extracted summary of each page. Quoted words are as extracted and were not compared
  byte for byte with the page. Read a page again before a sentence from it enters a contract.
- "Not stated" means the fetched pages did not state it, not that the host lacks it.
- No page shows a publication date or names a version for the three events. Locally installed at retrieval:
  Claude Code 2.1.321, codex-cli 0.167.0.
- The Claude Code hooks page (about 290,000 characters) was read in four windows; the Codex configuration reference
  for its first 100,000 of 164,000 characters. The Codex subagents page and the hook schemas in the Codex repository
  were not read.
